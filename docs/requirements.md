# 初期要件文書（履歴）

> **参考資料の所在(ローカル専用・git管理外)**: 画面・計算・仕分けルールの参考実装は `docs/reference/収支管理ダッシュボード.html`、要件定義は `docs/reference/収支統合管理システム_要件定義仕様書.md`。どちらも実明細・実金額を含むため `.gitignore` で除外しており、リポジトリには含めない。参考実装との差分一覧は [`spec-v1.1.md`](spec-v1.1.md) と `docs/product/backlog.md` に記録する。

このファイルは単一 HTML プロトタイプ時点の初期要件を起点とする履歴文書です。画面、計算契約、API、未実装項目の現行仕様はここでは管理しません。

- **現行仕様の唯一の正本**: [`spec-v1.1.md`](spec-v1.1.md)
- **統計指標の補足**: [`metrics.md`](metrics.md)
- **取込データ契約の補足**: [`data-schema.md`](data-schema.md)

履歴上の要求を変更するときは、本ファイルに重複定義を追加せず `spec-v1.1.md` を更新します。
