# 指標の定義

すべて「あなた自身の過去実績」から計算する相対指標であり、外部のベンチマークに依存しない。

## 基本統計

| 指標 | 定義 | 使いどころ |
|------|------|-----------|
| 平均 | 合計 ÷ 月数 | 「ふつうの月」の目安 |
| 中央値 | 昇順に並べた真ん中 | 平均と離れていれば「たまにドカンと使う月がある」 |
| 標準偏差 σ | 不偏分散の平方根（`n-1` で割る） | ブレ幅 |
| 基準レンジ | `平均 ± σ` | 約7割の月が収まる「いつも通り」の範囲 |
| 変動係数 CV | `σ ÷ 平均` | 金額の大小に依存せずブレの度合いを比較できる |
| zスコア | `(直近値 − 平均) ÷ σ` | z≧1 でやや高い、z≧2 で要確認 |
| 傾き | `直近3ヶ月平均 ÷ それ以前の平均 − 1` | +30%超で「構造的に増加」と判定 |

## 費目分類（CVによる）

CV が削減アプローチを決める。**金額の大きさではなく、ブレ方で手段が変わる**のがポイント。

| CV | 分類 | 削減アプローチ |
|----|------|---------------|
| < 0.6 | 固定費 | 契約の見直し（解約・プラン変更・年払い化） |
| 0.6 〜 1.5 | 準変動 | 頻度のコントロール |
| > 1.5 | スポット | 購入前の都度判断（年間換算で見る） |

## 事業指標

- **損益分岐点売上** ≒ 月間固定費（受託型サービス業のため変動費はほぼゼロ）
- **安全余裕率** = `(平均月商 − 損益分岐点) ÷ 平均月商` — 30%以上で健全、50%以上で優良
- **経費率** = `直近3ヶ月の平均経費 ÷ 平均月商` — フリーランスの目安は 20〜40%

## サブスク異常検知

ベンダーごとに、金額が0でない月の中央値 `med` を基準にする。

| 条件 | 判定 |
|------|------|
| `v ≧ med × 1.8` かつ `v > 20,000` かつ `med > 5,000` | 重複契約の疑い（同月複数請求） |
| `v ≧ med × 3` かつ `v > 15,000` | 急増（年払い切替・プラン変更の可能性） |

平均ではなく中央値を基準にするのは、異常値そのものが基準を引き上げてしまうのを避けるため。

## 削減の優先順位（会計実務の定石）

金額の大きい順ではなく、この順で手を付ける：

1. **重複・未使用** — ゼロコストで削れる
2. **固定費の契約条件** — 一度の作業が毎月効く
3. **変動費の頻度** — 継続的な努力が要る

売上を生む費用（研修費・ツール等の投資）を削るのは最後の手段。
