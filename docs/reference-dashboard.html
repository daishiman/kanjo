増減マトリクス — どの科目が増え、どの科目が減ったか

科目×月の全データ。「増減表示」に切り替えると前月比の増加が赤、減少が緑で表示され、増えている費目が一目でわかります。セルの色の濃さは金額の大きさです。右端に年計・前年比。

灰色セル＝記帳なし・対象外
読み方のコツ：「増減表示」で赤が縦に連続している科目＝継続的に増加している費目（要注意）。単発の赤＝スポット支出（年会費・機材購入など）。前年同月比で赤が続く科目は構造的なコスト増です。

統計診断 — 会計指標とコスト構造分析

各科目を「平均額・変動係数（CV）・直近3ヶ月の傾き・異常値（zスコア）」で診断します。CVが小さい＝毎月ほぼ一定の固定費（→契約見直しで削減）、CVが大きい＝スポット費（→都度判断で削減）。削減アプローチが違うため、まず分類が重要です。

科目別 統計プロファイル

*基準レンジ＝あなた自身の過去実績から計算した「いつも通り」の範囲（平均±標準偏差）。この範囲に収まっていれば正常、上に外れたら「いつもより使いすぎ」のサインです。統計の知識は不要で、判定列の色だけ見ればOK。仕組みの説明は「⑧ 指標ガイド」へ。傾き＝直近3ヶ月平均÷それ以前の平均−1。分類基準：固定費 CV<0.6／準変動 0.6–1.5／スポット >1.5。

損益分岐点と安全余裕率

受託型サービス業のため変動費はほぼゼロ。したがって損益分岐点売上 ≒ 月間固定費です。月商がこのラインを下回らない限り事業単体は黒字。安全余裕率 =（平均月商 − 損益分岐点）÷ 平均月商。70%超は極めて健全な水準です。

サブスク分析 — 最大コストの中身と重複検知

サブスク・通信費（2025年の「支払手数料」を含む統一基準）はベンダー別の積み上げで推移を確認します。特定ベンダーの帯が急に太くなった月＝プラン変更・重複契約のシグナルです。

予算管理 — 目標を決めて、予実で追う

科目ごとに月次予算（目標額）を設定してください。実績（直近月・3ヶ月平均）との差異が自動計算されます。「推奨値をセット」は統計プロファイルに基づく提案値（固定費＝直近実績の95%、スポット費＝全期間の月平均）です。設定した予算は「⑧ データ管理」の書き出しに含まれ、次回復元できます。

2. 一般的な目安（ベンチマーク）との比較

会計・FPの実務でよく使われる一般的な目安値です。あくまで参考値で、事業フェーズや家族構成によって適正値は変わります。判定はあなたの実データとの自動比較です。

3. 「削る費用」と「使うべき費用」の見分け方

費用の性質見分け方（この画面での場所）取るべきアクション
浪費（削る）③で「上昇」ピルが付き、売上との関係を説明できない費目。②増減マトリクスで赤が続く費目上限（予算）を⑥で設定し、超えたら即見直し
固定費（見直す）③で分類「固定費」の費目。金額が毎月ほぼ同じ年1回の契約棚卸し。重複・未使用を解約、年払い割引へ
投資（使うべき）研修費・書籍・ツールなど、3ヶ月以内に売上単価や受注に反映できる費目削らない。ただし「回収できたか」を四半期ごとに振り返る
スポット費（都度判断）③で分類「スポット」。機材購入・年会費など単発購入前に「年間換算でいくらか」を確認してから決裁
会計実務の原則：経費削減は「金額の大きい順」ではなく「①重複・未使用（ゼロコストで削れる）→ ②固定費の契約条件 → ③変動費の頻度」の順で行うのが定石です。売上を生む費用（投資）を削るのは最後の手段です。
