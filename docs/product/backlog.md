# 残課題リスト

「やらないこと」ではなく「順番を後にしたこと」。1件1行。書式: `- [分類] 内容 — 後回しにした理由`。
上から着手候補順。完了したら行を消し、PRで参照する。

## 次の候補(優先順)

- [機能] 明細ごとの大項目/中項目を、管理画面で登録した候補一覧から選んで手修正できるようにする(自由入力不可)。候補の初期値は取込済みデータの大項目/中項目と freee 勘定科目(サブスク・通信 / 新聞図書費 / 消耗品費 / 研修費 / 旅費交通費 / 前払費用 / 事業主貸 / 会議費 / 交際費 / 諸会費 / 雑費 / 広告宣伝費 / 売上高)から作り、架空の科目は入れない — 取込値と手修正を別枠で持つ新テーブル(D1の作り変え=マイグレーション+本番バックアップ)が必要で、UI調整のPRに混ぜると戻しにくくなるため分離した
- [機能] 仕分け画面に「月別の仕分けサマリー(事業/個人の件数・金額)」と「仕分けの考え方」の説明枠を追加する(参考実装にあり未実装) — 今回は見え方の修正を優先。集計は既存の /transactions summary で取れるため画面追加のみ
- [UX] 取込画面で失敗したファイルを「再取込」ボタンから同じ枠へ戻せるようにする — 現在は理由を読んでファイルを出し直す運用。失敗理由の表示で当面の迷いは解消したため
- [機能] 取込履歴に「誰が・どの画面から」の監査情報を持たせる(参考要件の監査履歴) — 1人運用のため優先度低
- [性能] 本番URLで Core Web Vitals を計測し、フォント(Zen Kaku Gothic New 全ウェイト同梱)の読み込みを絞る — 配布物にサブセット外のフォントファイルが大量に含まれており初回表示が重い可能性。計測してから対処
- [UX] 家計・サブスクの表をスマホ幅でカード表示に切り替える — 現状は横スクロールで閲覧可能。実機で困ってから
- [機能] 予算サマリーに「編集中の下書き」を即時反映する — 現在は保存後に反映。誤解を招くなら対応
