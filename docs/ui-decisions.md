# UI改善の判断記録(2026-08-24 / feat/ui-refresh)

リファレンスHTMLの見た目の忠実再現は要件から外れ、ベストプラクティス優先に変更(発注者指示)。色・フォントのデザイントークンはHTML版継承のまま。計算ロジック(spec §8)とスナップショット期待値は不変。

| 判断 | 採用 | 理由 / 却下案 |
|---|---|---|
| モバイルナビ | 下部固定タブバー(概況・マトリクス・仕分け・取込・メニュー)+ドロワー | 最頻4タスクを1タップに。却下: ハンバーガーのみ(全操作が2タップになる) |
| タブの選定 | 業務頻度順(毎日=概況/マトリクス、月次=仕分け/取込) | 残り7画面は「メニュー」から。5個上限の定石に従う |
| ナビの頭文字アイコン | 廃止(テキストのみ) | 漢字1字アイコンは判読性が低く、jp-web-designで禁止 |
| ヘッダーのアプリ名 | ホームへのリンク化 | 定石(現在地からの帰還手段)。h1はページ側のpage-titleが担う |
| 防衛ラインバッジ (FR-08) | 全幅で常時表示。狭幅は「見込」詳細のみ畳み、防衛線額+判定は残す | 完全非表示はFR-08違反。行を2段に折るのは高さを圧迫 |
| モーション | hover/pressed/ページ入場/ポップオーバーのみ、90〜200ms、reduced-motionで全停止 | 装飾アニメは追加しない |
| a11y | スキップリンク、:focus-visible統一(2px+offset)、Escape/外側クリックで閉じる、aria-expanded/haspopup、タップ領域確保 | |
| 表ヘッダー sticky | --header-h 変数で管理 | 53pxハードコードの分散を解消 |
